# Personal Mini-Toolkit

## What It Does

The Personal Mini-Toolkit is a menu-driven Python program containing three useful tools: a simple calculator, a to-do list, and a number checker. The calculator performs basic arithmetic, the to-do list allows users to manage tasks, and the number checker identifies properties of a number.

## How to Run

1. Make sure Python is installed on your computer.
2. Open a terminal in the project folder.
3. Run the program using:

```bash
python toolkit.py
```

4. Choose an option from the menu and follow the instructions.
5. Choose option 4 when you want to quit.

## Project Files

* `toolkit.py` — contains the complete Personal Mini-Toolkit program.
* `toolkit_plan.txt` — contains the planning and design for the toolkit.
* `README.md` — explains the project and how to run it.
* `screenshots/` — contains screenshots showing the program working.

## Reflection

The hardest part of the project was organizing several different tools inside one menu-driven program. The to-do list required the most thought because the list needed to change while the program was running. One useful bug to fix was making sure the program did not crash when the user entered invalid menu choices or invalid numbers. I also had to make sure the main menu returned after each tool finished. Using functions made the program easier to organize because each tool has its own section of code. I learned that loops are useful for keeping a program running while the user continues making choices. With one more week, I would add a password generator and a unit conversion tool to make the toolkit more useful.
